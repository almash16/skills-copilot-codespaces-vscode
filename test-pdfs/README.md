# Example PDFs

This directory can contain sample PDF files for testing the PDF Editor app.

## Adding Test PDFs

You can add your own PDF files here for testing purposes. For example:

- `sample.pdf` - A simple test document
- `presentation.pdf` - A presentation file
- `document.pdf` - A text document

## Note

PDF files are typically binary files and are excluded from git by default (they can be large). 

To test the app:
1. Add your own PDF files to this directory, or
2. Use the app's file picker to select PDFs from your device

## Creating a Test PDF

If you need a test PDF, you can:
- Create one using any word processor (save as PDF)
- Download sample PDFs from the internet
- Use online PDF generators
- Print any document to PDF

The app supports all standard PDF files.
